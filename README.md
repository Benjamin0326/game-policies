# game-policies

Public privacy policies for games by Benjamin0326 Dev.

## Tower Oops / 탑오정

- [한국어](https://benjamin0326.github.io/game-policies/tower-oops/ko/)
- [English](https://benjamin0326.github.io/game-policies/tower-oops/en/)

These policies are served via GitHub Pages from the `main` branch, `/(root)`.
For local preview, run `python3 -m http.server 8185 --bind 127.0.0.1` from this repository's root.

## Updating policies

Update the game-specific Korean and English pages together when data practices or integrated SDKs change. Confirm the effective date, update the app's Play Data safety declarations if applicable, and test publicly accessible HTTPS links after deployment.
