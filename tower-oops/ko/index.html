게임 데이터와 기기 내 저장

탑오정(Tower Oops)은 게임 진행, 동료 정보, 플레이어 표시 이름, 플레이 기록, 설정을 게임을 이어갈 수 있도록 기기에 저장합니다. 게임 자체 계정, 로그인, 개발자 서버에 저장하는 기능, 클라우드 동기화 기능은 제공하지 않습니다. Android 설정에서 앱 데이터를 지우거나 앱을 제거하면 해당 기기의 게임 데이터와 설정이 삭제됩니다.

Google 광고 및 동의 SDK

Android 앱에는 Google Mobile Ads Next-Gen SDK와 Google User Messaging Platform(UMP)이 포함되어 있습니다. 검토한 비공개 테스트 후보에서는 앱이 시작하는 광고 요청과 UMP 동의 요청이 비활성화되어 있습니다. 포함된 SDK의 자동 초기화, 식별자 접근 및 실제 네트워크 전송은 확인 대기 중입니다.

Google의 최신 광고 SDK 안내는 IP 주소(대략적인 위치 추정에 사용될 수 있음), 기기 및 계정 관련 식별자, 앱·광고 상호작용, 진단 정보가 광고, 분석, 부정 사용 방지에 쓰일 수 있다고 설명합니다. 앱에 포함된 SDK 버전과 출시 구성에서 실제로 처리하는 항목, 목적, 제공받는 주체, 사용자 선택, 보안, 보관 및 삭제는 확인 대기 중입니다.

지원 문의와 개인정보 요청

지원 이메일로 문의하면 답변을 위해 보낸 사람의 이메일 주소와 문의 내용을 사용할 수 있습니다. 문의 자료의 열람·정정·삭제에 관한 요청도 위 이메일로 보낼 수 있습니다. 메일 서비스 제공자와의 처리 관계, 보안 조치, 보관 기간, 삭제 방법 및 권리 행사 절차는 확인 대기 중입니다.
