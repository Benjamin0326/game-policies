2. 게임 진행 정보

게임은 진행 상태, 소환수와 장비 정보, 플레이어 표시 이름, 전투 및 플레이 기록, 설정 등을 이용자의 기기에 저장합니다. 해당 정보는 게임 진행과 이어하기, 설정 유지 및 기록 표시를 위해 사용됩니다. 게임 자체에는 계정 생성·로그인, 개발자가 운영하는 저장 서버, 자체 클라우드 동기화 기능이 없습니다. 개발자가 이 게임 기록을 원격 서버로 전송받는 기능도 구현되어 있지 않습니다.

검토한 Android 출시 후보에서는 앱 데이터의 Android 클라우드 백업을 비활성화했습니다. 다만 일부 Android 기기는 기기 간 이전 과정에서 앱 데이터를 복사할 수 있습니다. Android 설정에서 앱 데이터를 삭제하거나 앱을 제거하면 일반적으로 해당 기기에 저장된 데이터가 삭제되며, 다른 기기로 이전한 사본은 해당 기기에서 별도로 관리해야 합니다.

3. 선택형 보상 광고와 Google SDK

게임에는 사용자가 선택하여 보상을 받을 수 있도록 설계된 광고 기능이 있으며, Google Mobile Ads Next-Gen SDK 및 Google User Messaging Platform(UMP) SDK를 포함합니다. 광고의 실제 제공 여부는 앱 버전과 서비스 준비 상태에 따라 달라질 수 있습니다. 현재 검토된 첫 비공개 테스트용 Release 후보에서는 게임이 직접 실행하는 광고 초기화·요청 및 UMP 동의 갱신 요청을 비활성화해 광고가 표시되지 않습니다. 광고 기능이 비활성화되어 있다고 해서 포함된 SDK의 모든 데이터 처리가 없다고 단정하지는 않습니다.

Google의 Mobile Ads Next-Gen SDK 공개 자료에 따르면 SDK의 동작 및 설정에 따라 다음 정보가 Google에 수집·공유될 수 있습니다.

  • IP 주소: 연결 처리 및 대략적인 위치 추정에 사용될 수 있음
  • 기기·앱 식별자: Android 광고 ID, 앱 세트 ID 및 해당하는 기타 식별자
  • 앱·광고 이용 정보: 앱 실행, 광고 시청 및 사용자 상호작용
  • 진단 정보: 앱·SDK 성능, 실행 지연 및 오류 관련 정보

해당 정보는 광고 제공, 광고 성과 측정·분석, 부정 사용 방지 및 보안 목적에 사용될 수 있습니다. Google은 Mobile Ads Next-Gen SDK가 전송하는 사용자 데이터에 TLS 암호화를 적용한다고 안내합니다. 데이터 처리의 자세한 내용과 Google의 보관·삭제 기준은 Google 개인정보처리방침 및 Google 광고 SDK 데이터 공개 안내를 참고하세요. 이 공개 안내는 Google이 설명하는 최신 SDK를 기준으로 하며, 앱에 포함된 SDK 버전과 설정에 따른 실제 처리 범위는 다를 수 있습니다.

광고 관련 개인정보 동의 및 선택권은 해당 기능이 제공되는 버전과 이용 지역의 요건에 맞추어 제공됩니다. Android 설정에서 광고 ID를 재설정하거나 삭제할 수 있습니다. 광고를 시청하지 않아도 게임의 일반적인 플레이는 가능합니다.

4. 지원 이메일 문의

이용자가 직접 지원 이메일을 보내면 발신 이메일 주소, 문의 본문 및 이용자가 자발적으로 첨부한 자료를 받아 답변과 문제 해결에 사용합니다. 문의 처리를 위해 필요한 기간 동안 메일함에 보관하고, 문의 처리 목적이 달성되면 삭제합니다. 다만 관계 법령상 보존 의무가 있는 경우에는 해당 법령이 정한 기간 동안 보관한 뒤 삭제합니다. 메일 제공자가 자체적으로 보관하는 자료에는 해당 서비스의 정책이 적용됩니다.

문의 관련 개인정보에 대한 확인·정정·삭제 또는 처리 제한을 원하시면 위 이메일로 요청해 주세요. 적용 법령에 따라 요청을 확인하고 처리합니다. 이메일 문의는 사용자의 외부 메일 서비스와 Google의 메일 서비스 등을 거쳐 처리될 수 있습니다.

5. 대상 이용자 및 청소년

탑오정의 의도한 대상 이용자는 만 13세 이상입니다. 게임은 이용자의 생년월일을 직접 입력받는 기능을 제공하지 않습니다. 한국에서 만 14세 미만 이용자의 개인정보 처리에 법정대리인 동의가 필요한 경우, 관련 법령의 동의 및 확인 요건이 적용됩니다. 향후 광고 기능을 활성화할 때에는 이용자의 연령과 지역에 따른 개인정보 보호·동의 요건을 검토하고 필요한 보호조치를 적용해야 합니다. 청소년 또는 법정대리인은 위 이메일로 관련 문의를 할 수 있습니다.

6. 개인정보의 보호 및 외부 서비스

게임 진행 기록은 원칙적으로 기기 내부에서 처리됩니다. 광고·동의 기능이 사용되는 경우 Google이 관련 SDK 제공자로서 데이터를 처리할 수 있으며, 지원 문의는 이메일 제공자를 통해 처리됩니다. 개인정보처리방침 웹페이지는 GitHub Pages로 제공되며, GitHub는 서비스 보안을 위해 접속자의 IP 주소를 기록·보관할 수 있습니다. 웹페이지 자체에는 별도 분석 스크립트나 추적 쿠키를 삽입하지 않았습니다.

이들 외부 서비스의 데이터 처리 위치는 한국 외 지역을 포함할 수 있으며, 해당 서비스의 개인정보처리방침과 적용 법령에 따라 처리됩니다. GitHub 개인정보처리방침도 확인할 수 있습니다. 데이터의 처리 목적과 범위가 바뀌면 본 방침과 Google Play의 데이터 보안 정보를 함께 갱신합니다.
